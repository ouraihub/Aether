# 18 思考强度与用量统计

> 公共实施合同归Aether；AutoNote `docs/28-思考强度与用量统计设计及开发规划.md`是历史来源。Rust与`packages/core`复用本章类型、协议语义和共享界面；Worker由Aether `packages/worker`组合，产品仅注入模型/业务策略，验证记录见90。

## 1. 类型及字段

support导出ReasoningEffort（default/none/auto/minimal/low/medium/high/xhigh/max）、ReasoningDialect（openai/anthropic-budget/anthropic-adaptive/thinking-type/qwen）、ReasoningConfig { dialect, efforts: Vec<ReasoningEffort>, budget_tokens: Option<u32> }，camelCase。ReasoningConfig禁止default出现在efforts、禁止重复，非空，预算型预算>=1024；auto只允许thinking-type/qwen；qwen预算可省略，给出时>0。

Model、ProbedModel增加reasoning: Option<ReasoningConfig>（反序列化省略=>None，TS可选nullable）；ModelOption增加reasoning和contextWindow。Connection增加endpoint_id: Option<String>、reasoning。模型配置只在chat可用，dialect与协议匹配（openai只OpenAI两个协议，anthropic两种只Anthropic，thinking-type/qwen只OpenAI Chat）。未保存时按模型名、协议和线路地址推断已知族（AutoNote docs/28 §9.7，两端共用fixtures/reasoning-infer.json）；Responses的reasoning.summary只发给https://api.openai.com。

RunRequest增加reasoningEffort可选，缺省default；RunInput增加reasoning_effort。Runner独立校验非default必须在connection.reasoning.efforts。请求前失败不创建turn。RunEvent增加reasoning_delta{text}和context{usage:ContextUsage}；usage原inputTokens/outputTokens字段保留，扩展cacheReadTokens/cacheWriteTokens/reasoningTokens。TokenUsage为同名五个nullable u32；输入总数含缓存，输出总数含思考，明细不得再次加到总数。

ContextUsage { tokens: Option<u32>, context_window: Option<u32>, source: ContextSource(reported/estimated/unknown), endpoint_id: Option<String>, model_id: Option<String> }。最后请求输入+输出作为reported（必须input存在且完整结束）；估算按实际请求system/history/input/tools字符/3，失败/取消unknown。窗口来自connection而不是运行默认32k。每个请求刷新context；多轮usage累计，不用累计usage充当context。

上下文分三种用途：发送前预览是估算输入与输出预留；最近一次完整模型请求的 ContextUsage 是该请求占用；TokenUsage/Cost 是多轮消耗累计。三者不得替代。Aether 提供同语义的纯估算/预算与 ContextUsage 计算，输入包括实际 system/history/input/tools，模型/工具/草稿/历史/授权变化使宿主预览失效；裁剪哪些业务内容、计划 ID/CAS/有效期及用户确认归宿主。未知窗口不默认显示 32k，缺少供应商统计不填 0，取消/失败上下文未知。Rust RunSummary 必须保留实际最近上下文，不得事件有数据而返回值固定 None。

推理强度与公开摘要能力独立：公共 reasoning 校验/预算和协议编码同时覆盖 OpenAI Chat/Responses、Anthropic budget/adaptive、thinking-type 与 Qwen。宿主投影必须保留当前实现支持的完整 ReasoningConfig，不得因无公开摘要过滤允许档位；运行快照/历史绑定实际 endpoint/model，不用当前选择冒充历史。所有原始签名/加密块只用于同身份协议重放，不进入展示或日志。

TurnRecord/Turn现有input_tokens/output_tokens保留，增加cache_read_tokens/cache_write_tokens/reasoning_tokens、context_usage: Option<ContextUsage>、reasoning_effort、endpoint_id；旧数据库追加迁移、defaults保留旧消息。plugin Turn增加usage:TokenUsage、contextUsage、reasoningEffort、endpointId和reasoningText（只可展示的文本）。新增字段可空，不伪造旧统计。

## 2. 消息与执行

扩展既有Message::Assistant为text/tool_calls外加默认省略的reasoning:Vec<ReasoningBlock>。ReasoningBlock记录protocol、endpointId、modelId及供应商原值value，仅保存思考相关块，不能引入任意全响应透传。Anthropic thinking/signature/redacted_thinking按content block顺序保存；Responses保存reasoning item（id/summary/encrypted_content）并include encrypted_content、store=false；Chat保存reasoning_content。协议编码时保留原块并与原tool_use配对，身份不匹配时过滤reasoning块，不把思考变成普通文本。流式可展示摘要发reasoning_delta，redacted/encrypted不展示。

预算型档位minimal/low/medium/high/xhigh/max按预算上限5%/10%/50%/80%/90%/100%映射，最小1024，最大max_output-1；max_output<=1024拒绝。none禁用；default无控制。adaptive将允许的effort写output_config.effort，不发送预算；none禁用。OpenAI effort按用户声明值原样发送none/minimal/low/medium/high/xhigh/max；default不发送控制。

## 3. 共享界面

ModelPicker保留已有用户元数据；EndpointCard允许选中模型编辑reasoning dialect/允许档位/预算上限/contextWindow，复用整体保存。模型选择回调支持实际ModelOption，ChatPanel获取当前能力；RunSession接受reasoningEffort并保存每turnusage/context/reasoningText。运行中禁用选择；切模型重置default及旧context显示。使用已有Select/Popover/Input/Button，显示未知/估算/实测，上下文meter窗口未知不显示百分比；累计只统计已知值，详情保留未知。

## 4. 安全与验证

不加tokenizer或遥测。签名和加密块不进日志。验证三协议参数、工具轮重放、跨模型过滤、缓存语义、多轮累计、缺usage/窗口、取消/重生成、迁移和真实HTTP/IPC/UI。所有调用者更新，生成DTO由ts-rs统一生成，无兼容shim。实施后追加实际结果；未运行不得宣称验收。

## 5. 用量解析与费用（AutoNote docs/41）

桌面与 Web 解析一致：Anthropic 输入 = `input_tokens + cache_read_input_tokens + cache_creation_input_tokens`；OpenAI Chat 读 `prompt_tokens_details.cached_tokens`、`completion_tokens_details.reasoning_tokens`；Responses 读 `input_tokens_details.cached_tokens`、`output_tokens_details.reasoning_tokens`。

模型可配 `pricing`（`aether-support::ModelPricing`：币种 USD/CNY，1..8 档，每百万 Token 的输入/输出/缓存读/缓存写，缓存价为空时用本档输入价）。费用按**每一轮请求**选档并计算后求和：`uncached = max(0, input − cacheRead − cacheWrite)`，`amount = (uncached·input + cacheRead·cacheRead价 + cacheWrite·cacheWrite价 + output·output价) / 1e6`；任一轮缺输入或输出 Token、或无价格 → `cost = null`。`RunEvent::Usage.cost`、`Turn.cost`；回合结束时写入 `turns.cost/cost_currency`（chat.db v6），改价不重算历史。两端用共享 fixture `packages/ui/fixtures/pricing-cost.json` 校验一致。

2026-10-30真实双端场景发现原生Decoder尚未发出reasoning增量，不能以UI/协议编码存在代替执行证明。本轮补齐Chat reasoning_content、Responses公开summary/私有reasoning item、Anthropic thinking/signature/redacted块的接收；Round→Machine→Message保留原始块，重放同时匹配protocol/endpoint/model，签名和加密内容不进入展示。Responses显式store=false及include reasoning.encrypted_content。三协议真实HTTP回归与双端场景的最终结果见90。
