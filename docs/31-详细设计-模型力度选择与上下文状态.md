# 31 详细设计：模型/力度选择器与上下文用量状态

> 来源：LumaKit `lumakit-model-picker`、`lumakit-usage-status`（Rust/GPUI，已在 LumaDesk 与 ThinkRail Native 实窗验收）。本章把同一交互与语义移植为 `@ouraihub/aether-ui/chat` 的 Svelte 组件，供 AutoNote（桌面 Tauri 与 Web 两端）和 Actora 使用。代码、注释和标识符不写来源项目名。

## 1. 目标与范围

输入栏发送按钮左侧依次放两个控件，替换现有顶部 `ModelSelect`、输入栏 `ReasoningControl` 和齿轮 `UsageDetails` 入口：

1. **模型/力度选择器**：紧凑胶囊 `F gpt-6.1-sol ▮▮▯ 低 🔑 ⌄`，向上展开约 360px 浮层：
   - 搜索框「搜索模型…（可附加等级：opus high）」；
   - 按服务商分组，组头「F Fenno … API 密钥 · 默认线路 5 ⌄」，可折叠；
   - 模型行两行：名称（选中 ✓）与「🔑 默认线路 · USD 2 / 10 每百万 token 起 · 1.1M 上下文」；
   - 力度区「力度 · <模型>」：离散滑杆、档位文字（关闭/最低/低/中/高…，只列模型声明的档位）、档位说明（如「轻量推理 — 最快」）；
   - 提示行（如「已重新载入本地目录：5 个聊天模型」）；
   - 底栏「设为默认」「重置为 off」和右侧「刷新」。
2. **上下文用量状态**：`[系统图标] ~0.1%/1M [魔杖] · 1k tokens`；只有每条请求都有用户配置单价且同一币种时，第二段显示 `≈$1.52`／`≈¥1.52`。摘要按上下文压力着色，点击打开既有用量浮层（meter、本轮/累计 token 与费用表）。

不在范围内：改 Rust DTO、新增模型目录或偏好存储、服务商设置页布局、计费账单。

## 2. 现状（2026-11-05 核对 Aether `main` 1f5392a）

| 能力 | 现有实现 | 差距 |

宿主消费：AutoNote 三个 npm 清单与 Actora 两个清单均精确锁定 `@ouraihub/aether-ui@0.1.1` 并打补丁；新组件经新版本发布后到达宿主。AutoNote 桌面与 Web 都渲染同一 `packages/app` 的 `ChatPanel` 包装，内部即 Aether `ChatPanel`，因此两端同时获得改动；端口差异只在传输（Tauri IPC / HTTP），`providers.list()`、`modelOptions()` 两端都有。

## 3. 数据契约（纯 TS，无 Rust/DTO 变更）

```ts
// chat/model-effort.ts
export interface PickerModel {
  key: string              // 不透明身份，ChatPanel 用 `${endpointId}\n${modelId}`
  providerId: string       // 分组身份
  provider: string         // 组头显示名
  name: string             // 模型显示名
  detail: string           // 「线路 · 价格 · 窗口」，宿主或 pickerModels 生成
  hasKey: boolean          // 线路有已启用密钥；无密钥仍可选
  efforts: ReasoningEffort[] // 模型声明档位（不含 default），升序
  contextWindow: number | null
}
export interface PickerValue { key: string; effort: ReasoningEffort } // effort 'default' = 不发送控制
export function pickerModels(options: ModelOption[], providers: Provider[] | null): PickerModel[]
```

- `pickerModels` 按 `endpointId/modelId` 关联 `Provider.endpoints[].models[]`：价格取首档「`USD 2 / 10 每百万 token 起`」，窗口按 `1.1M`/`200K`/`512` 上下文显示；`providers` 加载失败或缺项时省略对应片段，不猜测。组头副标题「API 密钥 · <线路 slug> <模型数>」，`hasKey` = 存在 `enabled && readable` 的密钥。
- 档位文本复用 `chat.effort.*`；新增 `chat.effortHint.*`（none「无推理 — 最快·最省」、minimal「最简推理」、low「轻量推理 — 最快」、medium「均衡推理」、high「深度推理」、xhigh「超深度推理」、max「最高推理」、auto「由服务商自动决定推理深度」、default「使用服务商默认强度」）。
- Actora 用自己的模型别名视图映射为 `PickerModel`，无价格时 `detail` 只含线路与窗口。

## 4. 组件

### 4.1 `ReasoningSlider.svelte`（从 `ReasoningControl` 抽出，二者共用）

原生 `range`（step=1，透明，thumb 与胶囊等宽）叠在轨道上，props `efforts`、`value`、`defaultIndex`、`disabled`、`label`、`valueText`、`onchange`。外观对齐 LumaKit `lumakit-model-picker/src/rail.rs`：相邻档位色调渐变填充到当前位置，胶囊 thumb 显示档位图标（`icons/effort-icons.ts`，与 LumaKit 相同的 Remix 形状：关闭 Zzz、最低 Leaf、低 Flashlight、中 ContrastDrop2、高 Sparkling2、很高 Sparkling、最大 Fire）与名称。色调 none/minimal/low = info，xhigh/max = warning，其余 primary，只用主题变量。

### 4.2 `ModelEffortPicker.svelte`

```ts
props: {
  models: PickerModel[]; value: PickerValue | null; defaultValue?: PickerValue | null
  disabled?: boolean; refreshing?: boolean; notice?: string; i18n: KitI18n
  open?: boolean /* $bindable */
  onselect: (value: PickerValue) => void
  onsetdefault?: (value: PickerValue) => void   // 缺省则隐藏「设为默认」
  onrefresh?: (force: boolean) => void          // 打开时 false，点「刷新」true
}
```

行为合同（有组件测试，与 Rust 版对齐）：

- **受控**：组件不乐观提交；选择只发 `onselect`，宿主更新 `value` 后状态才改变。`disabled` 时选择与「设为默认」禁用，刷新仍可用。
- **打开**：清空搜索、聚焦搜索框、调用 `onrefresh(false)`；当前模型所在组自动展开。`Popover.Portal` 向上左对齐，宽 `min(360px, 视口-16)`；Esc 关闭并把焦点交还胶囊。
- **列表**：`bits-ui.Command` 提供搜索框、键盘导航、`role="option"`、分组与空态；`shouldFilter={false}`，过滤与排序由 `model-effort.ts` 负责。末位词为已知档位（off→none、minimal、low、medium、high、xhigh、max、auto）时按前半段搜索，并要求模型声明该档位；搜索时各组展开，可单独折叠。
- **切换模型**：搜索带档位后缀用该档位；否则保留当前显式档位（新模型声明了才保留）；否则 `default`。永不自动选第一档或中位。
- **力度区** `PickerEffort.svelte`：>1 档时有 `ReasoningSlider`；档位按钮用 `bits-ui.ToggleGroup` 单选；非 `default` 时显示「恢复默认」。模型未声明档位时显示未配置提示与（宿主传入时）打开设置入口。拖动/方向键/点档位才写值，打开不写值。
- 「**设为默认**」：宿主提供 `onDefaultModelChange` 才显示；当前值为空或与默认相同时禁用。「**重置为 off**」：当前模型声明 `none` 才可用。「**刷新**」：`refreshing` 时显示「更新中…」并禁用。
- **胶囊**：服务商首字母 + 模型名（截断）+ 4 根强度条（点亮数 = 档位序号/推理档位数×4，不计 none）+ 档位文字 + 🔑（`hasKey`）+ ⌄；`aria-label` 为 `chat.picker.trigger`。
- **空态**：`Command.Empty`（`forceMount`）显示 `chat.picker.empty`／`chat.picker.noMatch`。

### 4.3 `ContextUsageStatus.svelte`

```ts
props: {
  context: ContextUsage | null; contextWindow?: number | null  // 回退：选中模型窗口
  turns: readonly { usage: TokenUsage | null; cost: Cost | null }[]
  modelName?: string; i18n: KitI18n; platform?: Platform       // 缺省自动检测
  settings?: Snippet; details?: Snippet; open?: boolean        // 透传给 UsageControl 浮层
}
```

- 摘要：`{估算?'~':''}{百分比 1 位}%/{窗口紧凑}`；未知为 `?`，百分比限 0–100，窗口未知不显示百分比。紧凑计数用整数截断（999 999 → `999.9k`，不进位成 `1000k`）。
- 第二段（`spending`）：存在用量的每一轮都有 `cost` 且只有一种币种 → `≈$x.xx`／`≈¥x.xx`（<0.01 显示 4 位，<0.0001 显示 `<0.0001`）；否则显示累计 `input+output` 的紧凑 token（缓存含在输入、思考含在输出，不重复加）；没有任何已知用量 → `? tokens`。不显示美元未知占位，不套用目录参考价，不换算币种。
- 压力（OMP 阈值，窗口已知才比较绝对 token）：≥90% 或 ≥500k → critical（destructive）；≥70% 或 ≥270k → high（warning 与 destructive 的 `color-mix`）；≥50% 或 ≥150k → warning；否则 muted。颜色只用主题变量。
- 图标：系统标志（Windows/macOS/Linux，其它不显示）用前景色；魔杖跟随压力色，仅为状态标记，不是压缩按钮。平台检测 `navigator.userAgentData?.platform ?? navigator.platform`，宿主可用 `platform` 覆盖；Web 端显示的是浏览器所在系统。
- 交互：整个摘要是按钮，打开既有 `UsageControl` 浮层（`UsageControl` 新增可选 `summary` snippet 与 `summaryLabel`，meter 与明细不复制）；`aria-label` 为 `chat.status.label`，含完整数值与「查看用量详情」。窄宽度下第二段先截断，摘要与发送按钮不换行挤压。

### 4.4 组件边界与规范遵循

- 按 `.claude/skills/shadcn-svelte` 规则：布局用 Tailwind 工具类，颜色只用语义 token，条件类名经 `#lib/utils.cn`；不写 `space-y-*`、`dark:` 覆盖或原始色值。按钮用 `variant`/`size`，按钮内图标加 `data-icon`、不加尺寸类。
- 优先用现有组件：模型列表 `bits-ui.Command`（同仓库 `providers/ModelSelect.svelte` 同样用法）、档位 `bits-ui.ToggleGroup`、分隔线 `#lib/components/ui/separator`。直接用 bits-ui，不经 CLI 新增 `components/ui` 文件。
- 非 Lucide 的系统标志与魔杖经 `chat/icons/PathIcon.svelte` 作为组件传入；path 常量与 Remix、Simple Icons 许可放在 `chat/icons/`。
- 浮层 `z-[210]` 沿用仓库现有四个浮层的层级约定（需盖过宿主对话框），未改动该约定。
- 文件规模（≤500 行）：`ModelEffortPicker` 308、`PickerEffort` 72、`ReasoningSlider` 155、`ContextUsageStatus` 92、`ChatPanel` 499；模型目录加载在 `chat-panel-models.svelte.ts`。

## 5. 宿主接入

### 5.1 Aether `ChatPanel`（AutoNote 桌面与 Web 共用）

- 加载 `modelOptions` 时并行 `ports.providers.list()`（失败只降级 detail，不阻断选择），`pickerModels` 生成数据；`providersRevision` 变化或 `onrefresh` 时重新加载，完成后 notice「已重新载入本地目录：N 个聊天模型」，失败显示错误。
- `ChatPanelHeader` 移除 `ModelSelect`；`ChatPanelComposer` 的 actions 依次：`ChatPanelMode`（仅非 `chat` 用途）、`ModelEffortPicker`、`ContextUsageStatus`（内含 `UsageDetails` 明细），删除独立 `ReasoningControl` 和齿轮入口。
- `ChatPanelProps` 新增 `defaultModel?: ModelRef | null` 与 `onDefaultModelChange?: (ref, effort) => void | Promise<void>`；选择仍是会话内临时覆盖，`nearestEffort` 与偏好策略不变。
- 文件规模：`ChatPanel.svelte` 保持在 500 行内（499），模型目录加载、默认保存与选择映射放进 `chat-panel-models.svelte.ts` 状态类（不用参数属性/enum/namespace，满足宿主 `erasableSyntaxOnly`）。

### 5.2 AutoNote（`E:/workspace/notepad-dev/dev/AutoNote`）

- `packages/app/src/features/ai/chat/ChatPanel.svelte` 传 `defaultModel`（`chat` 角色绑定）和 `onDefaultModelChange`（`setRole('chat', ref)` + 保存力度偏好）。桌面经 Tauri `ai_roles_set`，Web 经 `PUT /api/ai/roles`，同一端口抽象，组件无平台分支。

- AI 侧栏宽度可拖动（360–760，默认 440，双击恢复，`layout.assistWidth` 持久化）。
