## 1. 执行协议

1. 只领**依赖全部完成**的任务；编号不是顺序。
2. 读完对应设计章节，再读蓝本代码；不凭记忆推断接口。
3. 只做该任务。发现设计错误先改文档，再改代码；不写兼容补丁。
4. 真实验证：纯函数与边界单测；网络用本地可控上游（loopback HTTP / 假 MCP 服务）跑真实请求；界面在 `examples/*` 真实 Tauri 窗口操作并截图；发布前用真实服务联验。测试验证宿主可见行为，不用"类型存在""调用被转发""源码包含某字符串"冒充功能证明。
5. 门禁：`cargo fmt --check`、`cargo clippy --workspace --all-targets --all-features -- -D warnings`、`cargo test --workspace --all-features`、每个 feature 单独 `cargo check -p tauri-plugin-aether --no-default-features --features <f>`、`pnpm -r typecheck`、`pnpm -r test`、`pnpm -r lint`、`pnpm kit:dto-check`、`pnpm kit:i18n`。
6. 记录：任务行写日期、变更文件、命令与结果、关键读回值、未验证项。全部判据通过才改 `[x]`。
